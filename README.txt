MI ESTUDIO FACIL - INSTRUCCIONES

1. PROBAR EN VISUAL STUDIO CODE
- Descomprime mi_estudio_facil.zip.
- Abre Visual Studio Code.
- Selecciona Archivo > Abrir carpeta y elige mi_estudio_facil.
- En Extensiones instala "Live Server" (autor Ritwick Dey).
- Abre index.html y pulsa "Go Live" abajo a la derecha.

2. PUBLICAR EN GITHUB
- Entra en https://github.com e inicia sesión.
- Pulsa + > New repository.
- Nombre: mi-estudio-facil. Selecciona Public y crea el repositorio.
- En el repositorio pulsa "uploading an existing file".
- Arrastra TODOS los archivos de la carpeta del proyecto al área de carga. No subas solamente el ZIP.
- Pulsa Commit changes.
- Entra en Settings > Pages.
- En Build and deployment elige "Deploy from a branch".
- En Branch elige "main" y carpeta "/ (root)". Pulsa Save.
- Espera unos minutos. La dirección publicada aparecerá en Settings > Pages.

3. INSTALAR
- Abre la dirección publicada en Chrome o Edge.
- Si el navegador ofrece instalar, usa el botón "Instalar aplicación" o la opción de instalación del menú.
- Abre primero la app con Internet para guardar sus archivos y permitir el uso sin conexión.

IMPORTANTE
- GitHub Pages requiere Internet en la primera visita y para descargar actualizaciones.
- Materias, apuntes, tareas y resultados se guardan localmente en ese navegador y dispositivo.
- No se sincronizan entre equipos y no hay cuentas ni copia de seguridad en la nube.
- Evita borrar los datos del sitio o usar navegación privada si quieres conservarlos.
- Para actualizar la app, sube los archivos nuevos al mismo repositorio y conserva la configuración de Pages.
